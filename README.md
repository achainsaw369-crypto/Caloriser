# Счётчик калорий

Веб-приложение для подсчёта калорий и БЖУ (в духе FatSecret).

## Возможности

- **Дневник питания** по датам: стрелки ‹ › для перехода по дням, выбор даты из календаря (нажмите на заголовок), кнопка «Сегодня».
- **Приёмы пищи** — завтрак, обед, ужин, перекус; у каждого своя кнопка «+» для добавления еды, итоги ккал и БЖУ.
- **Поиск продуктов**:
  - [Open Food Facts](https://openfoodfacts.org) — открытая база (миллионы упакованных товаров, есть российские), без ключа API;
  - поиск по **штрихкоду** — введите цифры (8–14 знаков) в строку поиска;
  - встроенный справочник базовых продуктов (крупы, мясо, молочка, овощи, фрукты…) — работает офлайн.
- **Свои продукты** — ввод БЖУ и калорий на 100 г (если калории не указаны — считаются по БЖУ).
- **Свои блюда (рецепты)** — из любых продуктов; учитывается количество порций и вес готового блюда (уварка/ужарка). Блюдо добавляется в дневник порциями или граммами.
- Цели на день (ккал, Б/Ж/У), экспорт/импорт данных в JSON.

Данные хранятся в `localStorage` браузера.

## Запуск

```powershell
npm install
npm run dev
```

Открыть http://localhost:5173. Сборка для публикации: `npm run build` (результат в `dist/`).

## Публикация на GitHub Pages

В репозитории уже есть workflow `.github/workflows/deploy.yml`: при каждом push в ветку `main`
GitHub сам соберёт проект и опубликует его.

1. Создайте пустой репозиторий на GitHub (без README).
2. Загрузите код (см. ниже).
3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Откройте вкладку **Actions** — после зелёной галочки сайт доступен по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Загрузка через git:

```powershell
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
git push -u origin main
```

## Структура

```
src/
  core/          ← логика без React/DOM — переносится в нативное приложение как есть
    types.ts         модели данных
    nutrition.ts     расчёты КБЖУ, рецепты
    store.ts         хранилище состояния + интерфейс StorageAdapter
    foodApi.ts       Open Food Facts (поиск, штрихкод)
    builtinFoods.ts  встроенный справочник
    search.ts        локальный поиск
    dates.ts         работа с датами
  platform/
    webStorage.ts    StorageAdapter на localStorage
  ui/            ← веб-интерфейс (React)
  state.ts       экземпляр стора + хук useAppData
```

## Путь к нативному приложению

Рекомендуется **React Native (Expo)**:

1. Папка `src/core` копируется (или выносится в общий пакет монорепозитория) без изменений.
2. Пишется `StorageAdapter` на `AsyncStorage` или `expo-sqlite` вместо `webStorage.ts`.
3. Экраны в `src/ui` переписываются на компоненты React Native — структура экранов и логика потоков (выбор продукта → количество → добавление) остаются теми же.
4. В нативной версии удобно добавить сканер штрихкодов камерой (`expo-camera`) — поиск по коду уже реализован в `lookupBarcode`.
